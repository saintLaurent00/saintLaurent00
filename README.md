## 👁️ About

I am a **Software Engineer focused on Data Engineering, Business Intelligence and analytical systems**.

I build software that sits at the intersection of:

* **Software Engineering** — backend systems, APIs and high-performance services
* **Data Engineering** — data pipelines, transformation, modeling and analytical infrastructure
* **Business Intelligence** — semantic layers, analytics and data visualization
* **AI** — intelligent systems and data-driven decision making

My current technical focus is on building **reliable, modular and high-performance data systems** using Rust, Go, Python, SQL, PostgreSQL and dbt.

> **My goal:** turn raw data into reliable systems, useful insights and better decisions.

### 📊 BI-Plateforme

A modular analytical platform designed around a clear separation of responsibilities:

```text
Authentication / IAM
        ↓
Semantic Layer + Permissions
        ↓
Analytical Query Engine
        ↓
PostgreSQL
        ↓
BI / Analytics
```

The platform explores:

* Go-based authentication and IAM
* Semantic metadata and row-level security
* Rust-based analytical query execution
* Background synchronization and reporting
* dbt-based data transformation
* Dockerized infrastructure

**Focus:** Data Platforms · Analytics Engineering · Backend Systems · BI

### 👁️ GEMINI_GOLD_EYE

An experimental AI-assisted trading analysis system combining **mathematical rules with multimodal AI**.

```text
Market Data
     ↓
Technical Indicators
     ↓
Rule-Based Strategy
     ↓
Chart Generation
     ↓
Gemini Vision
     ↓
BUY / SELL / WAIT
     ↓
Risk Management
     ↓
Backtesting / Paper Trading
```

The project explores:

* multimodal AI
* quantitative analysis
* technical indicators
* backtesting
* risk management
* API integration
* modular Python architecture

> Experimental project. Financial markets involve significant risk; backtests do not guarantee future performance.
