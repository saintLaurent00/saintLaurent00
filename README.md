## 👁️ About Me

I'm **Laurent Ouattara**, a Software Engineer and builder from **Côte d'Ivoire**.

I like understanding how things work beneath the surface — then turning that understanding into software.

My interests sit at the intersection of:

**Software Engineering · Data · Systems · AI · Security**

I build and experiment with systems ranging from business applications and analytical platforms to AI-assisted tools and low-level software.

I'm particularly interested in **how data flows through a system, how software processes it, and how intelligent systems can transform it into useful decisions.**

But my ambition goes beyond a single technology or job title.

I want to become the kind of engineer who can:

```text
Understand the problem
        ↓
Design the system
        ↓
Choose the right technology
        ↓
Build the software
        ↓
Process & understand the data
        ↓
Add intelligence where it matters
        ↓
Ship something useful
```

> **I don't want to simply use technology. I want to understand it, build with it, and eventually push its limits.**

## 🏗️ What I'm Building

### 📊 BI-Plateforme

A modular analytical platform exploring how a modern BI system can be engineered from the ground up.

```text
Authentication / IAM
        ↓
Semantic Layer
        ↓
Permissions / RLS
        ↓
Analytical Query Engine
        ↓
Data Layer
        ↓
BI / Analytics
```

**Rust · Go · PostgreSQL · dbt · Docker**

The project is an exploration of:

* analytical query engines
* semantic layers
* data platforms
* high-performance backend systems
* BI architecture
* secure data access
